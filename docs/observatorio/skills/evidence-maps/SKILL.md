# Skill: mapas de evidencia trazable

## Cuándo usar

Usar para datos de congresos, publicaciones, justicia o gasto con geografía y
definición verificable. No usar para decorar una cifra sin localización.

## Procedimiento

1. Definir unidad, período, fuente, universo y base geográfica.
2. Mantener `null` como desconocido; nunca convertirlo en cero.
3. Separar stock, flujo, muestra y parte de prensa.
4. Para un gradiente, usar una métrica comparable dentro de una sola colección.
5. Para calor, agregar antes de publicar, suprimir grupos pequeños cuando haya
   riesgo de identificación y declarar radio/zoom como decisiones visuales.
6. Añadir tooltip con nombre, valor, unidad y cobertura.
7. Documentar si el punto es sede, institución, centroide o lugar del hecho.
8. Exportar el agregado y enlazar la fuente.
9. Probar fallback sin teselas y en viewport móvil.

## Reglas bibliométricas

- Afiliación de autoría no es sitio del estudio ni nacionalidad del autor.
- Un trabajo puede contar en varios países e instituciones.
- Las citas dependen de edad, disciplina e indexación; no miden calidad clínica.
- Una muestra por citas no representa toda la producción.
